# 🌐 EDIS Web Interface - Руководство по запуску

## 📋 Что это?

Киберпанк-интерфейс для удаленного управления вашим EDIS (Dual Qwen Brain). Позволяет управлять AI-агентом с любого устройства через красивый веб-интерфейс.

## 🚀 Пошаговая инструкция

### Шаг 1: Запуск Backend на сервере

**На вашем сервере с H200:**

```bash
# 1. Установите зависимости
cd /path/to/EDIS_ASSISTANT
pip install -r web/backend/requirements.txt

# 2. Установите API ключ (для безопасности)
export EDIS_API_KEY="придумайте-сложный-ключ-здесь"

# 3. Запустите backend
cd web/backend
python main.py
```

Backend запустится на `http://0.0.0.0:8000` (доступен из сети).

**Проверка:** Откройте в браузере `http://YOUR_SERVER_IP:8000` - должны увидеть JSON с информацией о сервисе.

### Шаг 2: Запуск Frontend на локальном ПК

**На вашем компьютере (Windows/Linux/Mac):**

#### Вариант A: Автоматический запуск (рекомендуется)

**Windows:**
```bash
cd C:\path\to\EDIS_ASSISTANT
start_web.bat
```

**Linux/Mac:**
```bash
cd /path/to/EDIS_ASSISTANT
chmod +x start_web.sh
./start_web.sh
```

#### Вариант B: Ручной запуск

```bash
cd web/frontend

# Установка зависимостей (только первый раз)
npm install

# Создание конфигурации
cp .env.example .env.local

# Отредактируйте .env.local:
# NEXT_PUBLIC_API_URL=http://YOUR_SERVER_IP:8000
# NEXT_PUBLIC_API_KEY=ваш-api-ключ

# Запуск
npm run dev
```

### Шаг 3: Настройка подключения

1. Откройте браузер: `http://localhost:3000`
2. Нажмите на иконку ⚙️ (Settings) в правом верхнем углу
3. Введите:
   - **Server URL:** `http://YOUR_SERVER_IP:8000`
   - **API Key:** ваш ключ из `EDIS_API_KEY`
4. Нажмите **RECONNECT**

Если всё настроено правильно, статус изменится на 🟢 **CONNECTED**.

### Основные функции

1. **Task Input** - Отправка задач агенту
   - Введите задачу
   - Выберите приоритет (Critical/High/Medium/Low)
   - Включите Task Graph для декомпозиции
   - Нажмите EXECUTE TASK

2. **Autonomous Log** - Живой поток мыслей EDIS
   - Видите всё, что делает агент в реальном времени
   - Поддержка Markdown и подсветка кода
   - Автоскролл (можно отключить)

3. **System Stats** - Мониторинг сервера
   - Количество GPU
   - Использование памяти
   - Активные задачи
   - Время работы

## 🔧 Настройка firewall

Чтобы подключиться к серверу из сети, откройте порт 8000:

**Ubuntu/Debian:**
```bash
sudo ufw allow 8000/tcp
```

**CentOS/RHEL:**
```bash
sudo firewall-cmd --permanent --add-port=8000/tcp
sudo firewall-cmd --reload
```

**Windows Server:**
```powershell
New-NetFirewallRule -DisplayName "EDIS Backend" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
```

## 🐛 Решение проблем

### ❌ "DISCONNECTED" в интерфейсе

**Причины:**
1. Backend не запущен на сервере
2. Неправильный IP адрес в настройках
3. Firewall блокирует порт 8000
4. Неправильный API ключ

**Решение:**
```bash
# На сервере проверьте, что backend работает:
curl http://localhost:8000

# Проверьте доступность из сети:
curl http://YOUR_SERVER_IP:8000

# Проверьте логи backend:
cd web/backend
python main.py
```

### ❌ "Failed to create task"

**Причины:**
1. Неправильный API ключ
2. Агент не инициализирован

**Решение:**
- Проверьте, что `EDIS_API_KEY` совпадает на сервере и в `.env.local`
- Проверьте логи backend на наличие ошибок

### ❌ WebSocket не подключается

**Причины:**
1. Proxy/VPN блокирует WebSocket
2. Неправильный протокол (должен быть ws://)

**Решение:**
- Откройте DevTools (F12) → Console
- Проверьте ошибки WebSocket
- Попробуйте отключить VPN

## 📱 Доступ с других устройств

### С телефона/планшета

1. Убедитесь, что устройство в той же сети, что и ПК с фронтендом
2. Узнайте IP вашего ПК:
   - Windows: `ipconfig`
   - Linux/Mac: `ifconfig` или `ip addr`
3. Откройте на телефоне: `http://YOUR_PC_IP:3000`

### Через интернет (продвинутый вариант)

Используйте reverse proxy (nginx) или туннель (ngrok, cloudflare tunnel).
