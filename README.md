# Dual Qwen Brain - Мультимодальный агент

Автономная агентная система на базе двух специализированных моделей Qwen, имитирующая функциональную асимметрию человеческого мозга.

## Архитектура

- **Творец (Qwen-72B)**: Креативное полушарие с высокой температурой для генерации гипотез
- **Логик (Qwen-398B)**: Аналитическое полушарие с низкой температурой для верификации и исполнения

## Установка

```bash
pip install -r requirements.txt
```

## Структура проекта

```
dual_qwen_brain/
├── config/              # Конфигурационные файлы
├── core/                # Ядро системы
│   ├── models/          # Обертки для Qwen моделей
│   ├── workflow/        # LangGraph workflow
│   └── memory/          # Векторная память (Qdrant)
├── agents/              # Агенты (Творец, Логик)
├── autonomy/            # Система автономного мониторинга
├── training/            # Скрипты DoRA fine-tuning
└── tools/               # Инструменты (GitHub, Tavily)
```

## Использование

```python
from dual_qwen_brain import DualQwenAgent

agent = DualQwenAgent()
result = await agent.process("Создай архитектуру для распределенной системы")
```

## Режимы работы

1. **Interactive Mode**: Прямое взаимодействие с пользователем
2. **Autonomous Mode**: Фоновый мониторинг и самообучение
